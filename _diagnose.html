檢查結果

依你的平台，���裝選項在這裡

iPhone / iPad（必須用 Safari）

  1. 用 Safari 打開（Chrome / Firefox on iOS 不會顯示安裝選項）
  2. 點底部中間的 分享 按鈕（方框向上箭頭）
  3. 在選單裡往下滑，找到 「加入主畫面」 → 右上角 「新增」
  4. iOS 16.4 以下會變成普通書籤（能用，但不會獨立視窗）

iOS 沒有浮動的安裝橫幅，只有分享選單裡那一項，很多人找不到就是這個原因。

Android（Chrome / Edge）

  1. 右上角 ⋮ 選單 → 「安裝應用程式」 或 「加入主畫面」
  2. 自動提示橫幅需要使用者先跟網站有互動，而且不一定會出現；直接用選單最可靠
  3. 若選單裡也沒有 → 看下面的檢查結果，通常是 manifest 或 Service Worker 的問題

桌面 Chrome / Edge

  1. 網址列右邊會出現一個 安裝圖示（電腦 + 箭頭）
  2. 或用 ⋮ → 鑄造安裝

最常見的五個原因

  1. iOS 上用了 Chrome/Firefox → 換 Safari
  2. Service Worker 註冊失敗 → Console 裡會有紅字（看下面的檢查結果）
  3. .webmanifest 的 MIME 錯了 → 必須是 application/manifest+json
  4. 網站不是 HTTPS → http:// 下不能安裝（localhost 除外）
  5. 瀏覽器已經裝過、或曾經忽略過提示 → 清除網站資料後重試
